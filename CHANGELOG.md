# Changelog

## 0.1.0 (unreleased)

- What Privilege did (Rule 25): under each run's trail, the shared `GatewayTrace` (vendored byte for byte from AI-DEMO-Standalone `shared/gateway-trace`, pinned by `web/src/gateway-trace/gateway-trace.sha256`) shows every call the attack made to the mock gateway: the exact request, the exact response and the decisions the gateway made in order (`createGateway().handle` now returns them, `server/src/galleryTrace.js` builds the trace). Mock only, so every decision is `checked`; a control that is OFF shows as information, never as passed; the token shows only its length. The two attacks the gateway never decides (confused deputy via DCR, SSRF) say so instead.
- Verification mark in the header: the shared `VerifyMark` (vendored from AI-DEMO-Standalone `shared/verify-mark`, byte for byte, pinned) shows this lab's Verified / In progress mark from the demo shelf, beside the Shelf link. It reads the same `GET /api/shelf` call the Shelf link makes, so it shows through the lab-proxy (where that call reaches the shelf) and nothing when the lab is opened on its own port, when the shelf has no mark for it, or when the shelf is unreachable.
